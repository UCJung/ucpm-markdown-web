# 지원 문법

| 항목 | 내용 |
|---|---|
| 설명 | 구조화 시각 편집 문법과 raw 보존 경계 |
| 생성일 | 2026-09-30 |
| 수정일 | 2026-09-30 |
| 버전 | 0.1.0 |

기본 Markdown과 GFM 일부는 구조화 문서로 변환·편집함. 변환하지 않는 블록은 원본 Markdown 문자열로 보존하며 시각 편집 대상에 포함하지 않음.

## 목차

| 번호 | 제목 | 설명 |
|---|---|---|
| 1 | 구조화 편집 | 현재 변환·직렬화 대상 |
| 2 | raw 보존 | 원본 문자열 보존 대상과 동작 |
| 3 | 정규화 | 허용되는 출력 차이 |

## 1. 구조화 편집

| 범주 | 지원 문법 | 시각 편집 |
|---|---|---|
| 블록 | 문단, 제목 1~6, 인용, 수평선, 일반·순서 목록, 코드 블록 | 지원 |
| 인라인 | 강조, 굵게, 취소선, 링크, 인라인 코드, 줄바꿈 | 지원 |
| GFM | 표, 체크리스트, 취소선, 자동 링크 | 지원 |

체크리스트와 일반 목록을 한 목록에 혼합하면 변환 오류 발생. 표 셀은 단일 문단을 기준으로 직렬화함.

## 2. raw 보존

| 입력 범위 | 처리 | 시각 편집 |
|---|---|---|
| block HTML | 원본 문자열 그대로 보존 | 미지원 |
| display math (`$$`) | 원본 문자열 그대로 보존 | 미지원 |
| directive block (`:::name`) | 원본 문자열 그대로 보존 | 미지원 |
| 미지원 mdast block | 원본 문자열 그대로 보존 | 미지원 |
| inline HTML·image·reference 등 미지원 inline | 포함 블록 전체를 원본 문자열로 보존 | 미지원 |

raw 블록은 텍스트로 렌더링하며 HTML·DOM·스크립트를 실행하지 않음. 인용·목록·표·문단 안의 raw 또는 미지원 inline은 컨테이너 전체를 raw로 보존함.

## 3. 정규화

| 대상 | 허용 차이 |
|---|---|
| 구조화 Markdown | 목록 기호, 표 공백, code fence, 문서 경계 줄바꿈 |
| raw 원본 | 허용 차이 없음 |

문서 끝이 구조화 블록이면 출력 끝에 한 줄바꿈을 추가함. 마지막 블록이 raw이면 원본 끝 개행을 추가하지 않음.
