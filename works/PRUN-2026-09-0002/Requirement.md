## 2. 배경 및 목적

- 해결하려는 문제: 프레임워크별 연결부와 분리된 편집기 코어의 공용 계약을 제공한다.
- 이해관계자: 라이브러리 소비자, 확장 개발자, 후속 Markdown·어댑터 REQ 개발자.
- 기존 시스템/프로세스 관계: `REQ-2026-09-0001`에서 구성한 6개 패키지 workspace를 사용하며, MVP 로드맵의 단계 1을 수행한다.

## 3. 범위

### In-Scope

- ProseMirror 기반 편집기 인스턴스의 생성·정리 lifecycle을 제공한다.
- 문서 schema, editor state, transaction 처리와 기본 명령을 제공한다.
- 변경 구독, history, keymap을 제공한다.
- 프레임워크 비의존 확장 등록과 lifecycle 계약을 TypeScript 타입으로 제공한다.
- 명령 실행과 변경 구독 API의 단위 테스트를 제공한다.

### Out-of-Scope

- Markdown 파싱·직렬화, GFM 변환, 미지원 원문 보존.
- DOM 기반 어댑터의 mount·destroy 동작과 playground 편집 기능.
- HTML 붙여넣기, 입력 규칙, 브라우저 상호작용 테스트.
- React·Vue 어댑터, UI 패키지, 협업 기능.
