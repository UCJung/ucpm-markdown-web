- 해결하려는 문제: 공개 npm 배포를 목표로 하는 WYSIWYG Markdown 에디터 MVP의 첫 REQ에 실행 가능한 패키지 작업 공간과 패키지 경계를 마련한다.

## 3. 범위

### In-Scope

- pnpm workspace와 TypeScript 기반의 실행 가능한 모노레포 기준을 제공한다.
- `core`, `markdown`, `extension-api`, `adapter-vanilla`, `extensions`, `playground`의 초기 패키지 경계를 제공한다.
- 패키지별 공개 진입점과 허용 의존성 경계를 정의한다.
- build, typecheck, unit test 명령을 실행할 수 있는 기준을 제공한다.
- Chrome, Edge, Firefox, Safari 최근 2개 주요 버전의 지원 대상을 문서화한다.

### Out-of-Scope

- 편집기 문서 모델, 명령, 확장 lifecycle 구현.
- Markdown 파싱·직렬화와 GFM 변환 구현.
- HTML 붙여넣기, 입력 규칙, 브라우저 상호작용 구현.
- Vanilla 어댑터 동작과 playground 편집 기능 구현.
- React·Vue 어댑터, UI 패키지, 협업 기능, 공개 npm 실제 배포.
